## 🎯 **Utilisation des Images SVG**

### **Avantages**
- ✅ **Scalable** : Qualité parfaite à toutes les tailles
- ✅ **Léger** : Fichiers de petite taille
- ✅ **Modifiable** : Facile à personnaliser
- ✅ **Performant** : Chargement rapide

### **Intégration HTML**
```html
<!-- Image SVG dans une carte de véhicule -->
<div class="vehicle-image">
    <img src="media/images/vehicles/citadine-economique.svg" 
         alt="Citadine économique Toyota Yaris" 
         class="vehicle-img">
    <div class="vehicle-badge">Économique</div>
</div>
```

### **Intégration CSS**
```css
.vehicle-img {
    width: 100%;
    height: 250px;
    object-fit: cover;
    transition: transform 0.3s ease;
}

.vehicle-img:hover {
    transform: scale(1.1);
}
```
