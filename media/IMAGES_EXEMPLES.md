## 🛠️ **Comment Créer ces Images**

### **Option 1 : Photos Réelles (Recommandée)**
1. **Photographiez** vos véhicules dans de beaux endroits
2. **Utilisez** un appareil photo de qualité (smartphone moderne OK)
3. **Choisissez** des angles intéressants et professionnels
4. **Éclairage** : lumière naturelle, évitez les ombres dures
5. **Contexte** : lieux emblématiques du Bénin (Cotonou, plages, etc.)

### **Option 2 : Banques d'Images**
1. **Unsplash** : Photos gratuites de haute qualité
2. **Pexels** : Images libres de droits
3. **Pixabay** : Photos et illustrations gratuites
4. **Adobe Stock** : Images professionnelles (payantes)

### **Option 3 : Création Graphique**
1. **Canva** : Outil en ligne simple et gratuit
2. **GIMP** : Éditeur d'images gratuit et puissant
3. **Photoshop** : Standard professionnel (payant)
4. **Figma** : Design collaboratif (gratuit pour usage personnel)

## 📊 **Spécifications Techniques**

### **Formats Recommandés**
- **Photos** : JPG/JPEG (qualité 85%)
- **Logos** : SVG (vectoriel, scalable)
- **Icônes** : SVG ou PNG (avec transparence)
- **Vidéos** : MP4 (H.264, optimisé web)

### **Tailles de Fichiers**
- **Images principales** : < 500KB
- **Images galerie** : < 300KB
- **Thumbnails** : < 100KB
- **Vidéo** : < 10MB

### **Optimisation Web**
- **Compression** : Optimisée pour le web
- **Lazy Loading** : Chargement différé
- **Responsive** : Adaptées à tous les écrans
- **Alt Text** : Descriptions accessibles

## 🎯 **Conseils de Production**

### **Qualité**
1. **Résolution** : Toujours plus haute que nécessaire
2. **Composition** : Règle des tiers, angles intéressants
3. **Éclairage** : Naturel et équilibré
4. **Couleurs** : Cohérentes avec votre marque

### **Cohérence**
1. **Style** : Visuel uniforme sur tout le site
2. **Palette** : Couleurs de marque respectées
3. **Traitement** : Post-production cohérente
4. **Format** : Même style de cadrage

### **Performance**
1. **Compression** : Optimisée sans perte de qualité
2. **Formats** : WebP + JPG pour compatibilité
3. **Lazy Loading** : Chargement intelligent
4. **CDN** : Distribution géographique
